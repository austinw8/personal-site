## Start
To run this site locally, make sure you have [Node.js](https://nodejs.org/) installed. 

Next, clone the repository then navigate into the project directory and install dependencies using

```bash
npm install
```

Start the development server with
```bash
npm start
```

The site will be available at `http://localhost:3000` and will automatically reload when you make changes.

## Code Quality

This project uses Prettier for code formatting and ESLint for code linting. Format and fix all code issues with:

```bash
npm run fix
```
